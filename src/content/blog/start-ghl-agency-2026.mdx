## The playbook

1. **One niche.** Dentists, roofers, realtors — pick where you have any edge. One snapshot, one offer.
2. **Three pilot clients, cheap.** $500 setup + $297/mo. You're buying testimonials and case data, not profit.
3. **Productize the snapshot.** Every install identical. Onboarding checklist: domain, A2P, Stripe, calendar, launch.
4. **Flip to SaaS mode.** $297–$497/mo retainers for the software + support. 20 clients × $297 = ~$6k MRR before services.
5. **Then scale acquisition.** Only now: content, outreach, ads.

## The math that matters

- Unlimited plan: $297/mo base. 3 clients at $297 covers it 3x.
- Churn kills: clients who get booked calls in week 1 stay. Speed-to-value > features.
- Support load: identical snapshots = one fix helps everyone. Custom builds per client = burnout.
